# Teams 聊天純文字匯出

在這台 Mac 上，以可見的專用 Chrome 視窗操作 Teams 網頁，讀取頁面中的訊息。**依需求略過所有頻道**，包含一對一、群組、靜音及會議聊天。工具不呼叫 Graph、Teams 內部 API，不擷取封包、不讀取 Teams 程式內部資料。Teams 網頁本身會正常連線載入訊息。

## 開始使用

需要 Node.js 20 以上及 Google Chrome。本機已安裝專案依賴。

```sh
cd "/Users/timchen/workspace/teams-exporter"
./teams-dump --login
./teams-dump
```

第一次在另外開啟的 Chrome 視窗登入公司 Teams。登入成功後會自動關閉並保存狀態；後續執行沿用同一專用設定檔。不要同時執行兩份工具。若公司登入要求 MFA，直接在視窗內完成，不需提供密碼給工具。

若已安裝全域命令，也可以從任意目錄執行 `teams-dump`。沒有全域命令時，以上 `./teams-dump` 或 `node src/cli.js` 效果相同。換一台電腦時先在此專案執行 `npm ci`。

## 指定時間

```sh
# 未指定參數：啟動當下往前 24 小時
./teams-dump

# 台北時間，包含 10/26 09:00，不含 10/27 09:00
./teams-dump --from "2026-10-26 09:00" --to "2026-10-27 09:00"

# 單一日期：台北時間當日 00:00
./teams-dump --from "2026-10-26" --to "2026-10-27"

# 可提供帶時區的 ISO 時間
./teams-dump --from "2026-10-26T09:00:00+08:00" --to "2026-10-27T09:00:00+08:00"
```

未指定 `--to` 就用啟動時間；只指定 `--to` 則從結束時間往前 24 小時。開始和結束時間會在啟動時固定，續抓不會向後延長。

## 匯出內容

預設在工具目錄的 `exports/<執行時間>/` 產生：

- `all.txt`：合併文字，依對話分組，每個對話按訊息時間排序。
- `conversations/*.txt`：各聊天的獨立文字檔。
- `report.txt`／`report.json`：列舉狀態、逐聊天狀態、訊息數、未完成原因及範圍限制。
- `state.json`：原始訊息與可續抓的進度，每讀取一批即保存。此檔可能包含跨過開始時間的前後文；文字檔只輸出範圍內及時間無法判定的訊息。

保留作者、完整時間、中文與多行文字、引用回覆原文、頁面可取得的連結及附件名稱。無法確認回覆目標識別值時保留引文，不推測對應訊息。圖片只保留描述，不做 OCR；不下載附件，也不開啟訊息內連結。

缺少完整時間的訊息會附上原始時間文字並標示「未確認是否在匯出範圍內」，也會讓該聊天維持部分完成。缺少穩定訊息識別值時，保留無法確認的重複項，避免刪掉不同的同內容訊息。

## 中斷與續抓

按一次 Ctrl+C，工具會保存並產生目前的文字檔及報告。再次執行：

```sh
./teams-dump --resume "exports/原本的工作目錄"
```

續抓保留原帳號、日期與目標範圍，跳過已完成聊天，重新檢查未完成聊天；有穩定識別值的訊息會去重。登入失效時等待重新登入，預設最多 10 分鐘，逾時後可再次續抓。帳號與原工作不一致會停止，避免混入其他帳號。

單一聊天載入出錯會重試最多三次，失敗後繼續其他聊天。每個捲動階段預設最多 2000 步；達到上限會標為部分完成，可提高 `--max-steps` 後續抓。

## 驗證與除錯

```sh
# 只抓一個精確名稱的聊天；若名稱重複會要求選擇不同的唯一名稱
./teams-dump --only "CSP PA OSC team"

# 調慢操作，等待較慢的網路載入
./teams-dump --delay 1500 --max-steps 4000

# 在專用視窗登入後輸出當前頁面的本機診斷，不執行完整匯出
./teams-dump --inspect

npm test
```

`--inspect` 產生 HTML、介面文字與畫面截圖，可能包含私人聊天內容；只在本機用於除錯。若 Teams 改版導致選擇器失效，工具應列出失敗或部分完成，不會把未載入的聊天當作零訊息成功。

## 完整度與已知限制

- 「掃描完成」表示清單到達重複確認的底部，且各聊天從最新訊息往前覆蓋指定開始時間，或遇到明確的起始／空白標記。穩定捲動頂部若沒有明確標記，仍保守標為部分完成。
- 本版掃描聊天清單可列舉的項目，展開資料夾及「See more」。不保證隱藏、封存或服務未提供的聊天可被列舉；報告會明列此限制。
- 系統通知、互動卡片及未公開完整時間的訊息可能無法完整解析；不要將結果視為稽核或法遵備份。獨立聊天討論串若出現會標示未支援／部分完成；一般引文回覆可保留。
- 不會因為聊天清單的最後活動早於範圍，就直接略過該聊天；逐一開啟驗證，因此聊天很多時可能花較久。
- 頻道全部排除，不會讀取舊貼文與頻道回覆。未實作定期排程、多帳號切換及已刪除訊息復原。
- 工具會操作專用視窗，可能將聊天標為已讀；匯出時不要手動切換該視窗的聊天。
- `.local/chrome-profile/` 含登入狀態；輸出含公司對話。目錄採使用者專用權限，不應分享整個工具資料夾或將這些資料加入 Git。
- 退出碼：`0` 掃描完成；`2` 部分完成或單一聊天驗證；`1` 執行錯誤；`130` 使用者中斷。

## 維護

`src/dom.js` 僅從頁面擷取；`src/adapter.js` 負責清單／捲動；`src/core.js` 負責日期、去重、進度與文字；`src/cli.js` 負責瀏覽器與指令介面。測試使用本機模擬頁面，不連線 Teams，也不需要真實帳號。
